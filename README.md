# Customer Churn Prediction & Retention Analytics

An end-to-end data analytics and machine learning project focused on identifying customer churn patterns, predicting customers at risk of leaving, and generating actionable retention insights.

## Project Overview

This project combines SQL, Python, Machine Learning, and Power BI to build a complete customer churn analytics workflow:

**SQL → Data Cleaning → Python/ML → Churn Prediction → Power BI → Business Insights**

### Key Components

* Cleaned and prepared customer data using SQL.
* Performed exploratory data analysis using Python, Pandas, NumPy, and Matplotlib.
* Built and evaluated classification models including Logistic Regression, Random Forest, and XGBoost.
* Analyzed important factors associated with customer churn.
* Created an interactive Power BI dashboard to monitor churn trends, customer segments, and high-risk customers.
* Generated business insights to support customer retention strategies.

## Tech Stack

* **SQL:** Data extraction, cleaning, transformation, and analytical queries
* **Python:** Pandas, NumPy, Matplotlib, Scikit-learn, XGBoost
* **Machine Learning:** Logistic Regression, Random Forest, XGBoost
* **Visualization:** Power BI, DAX, Power Query
* **Environment:** Jupyter Notebook

## Business Objective

The objective is to help businesses identify customers who are more likely to churn, understand the factors contributing to churn, and use data-driven insights to improve customer retention.
